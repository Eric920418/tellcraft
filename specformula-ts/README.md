# SpecFormula TypeScript

> **Status: Planned — 此套件尚未準備好**

## 目前狀態

TypeScript 版 SpecFormula 尚未開始開發。此資料夾為 placeholder，待後續實作。

### 尚未開始的原因

1. SpecFormula 四層模組架構目前僅有 Java 參考實作完成
2. TypeScript 需要設計對應的 BDD 整合方案（例如 Cucumber.js）
3. Database 抽象層需要對應到 TypeScript 的 ORM 體系（例如 Prisma / TypeORM）
4. HTTP 測試層需要對應到 Node.js 的 Supertest / Fetch 體系

### 開發路線

請參考 Java 參考實作 ([specformula-java/](../specformula-java/)) 作為移植基準。
