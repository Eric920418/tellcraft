### 尚未開始的原因

2. Python 需要設計對應的 BDD 整合方案（例如 Behave / Pytest-BDD）
3. Database 抽象層需要對應到 Python 的 ORM / DB-API 體系（例如 SQLAlchemy）
4. HTTP 測試層需要對應到 Python 的 HTTPX / Requests 體系
