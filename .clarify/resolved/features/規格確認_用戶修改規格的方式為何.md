# 釐清問題

PRD 提到「用戶確認 or 修改」規格書，但用戶如何修改？是透過對話還是直接編輯？

# 定位

Feature：規格書生成（Phase 2）
PRD Section 0.3 流程圖：「用戶確認 or 修改」

# 決議

**選項 A：僅透過對話修改**

修改方式：
- 用戶透過自然語言描述修改需求
- 例如：「把預約時段從 30 分鐘改成 1 小時」
- AI 解析意圖後更新規格
- 顯示變更前後對比，用戶確認

不提供規格編輯器的原因：
- 降低用戶技術門檻（不需懂 Gherkin/SQL）
- 確保規格一致性（AI 負責格式正確）
- 簡化 UI 複雜度

# 影響範圍

- 無需開發規格編輯器
- AI 需具備「增量修改」能力
- 需設計「變更確認」UI（顯示 diff）
