# 釐清問題

PRD 提到 Coder Agent 有「自癒迴圈（最多 3 次）」，但 3 次都失敗後怎麼辦？

# 定位

Feature：程式碼生成（Phase 5）
PRD Section 3.4：自癒機制

# 決議

**選項 A：標記為 failed，通知用戶，人工介入**

處理流程：
1. 3 次自癒都失敗後，Project status 設為 `failed`
2. 發送通知給用戶（Email / 站內通知）
3. 記錄失敗原因與測試結果供客服查看
4. 用戶可選擇：
   - 調整需求後重新嘗試
   - 聯繫客服協助處理
   - 申請退款（依退款政策）

不自動簡化規格或升級模型，避免產出與用戶期望不符的結果。

# 影響範圲

- 錯誤處理流程設計
- 通知系統整合
- 客服支援流程
- 計費政策（失敗是否扣用量 → 建議不扣）
