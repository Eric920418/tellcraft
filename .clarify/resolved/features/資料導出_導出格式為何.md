# 釐清問題

決議「取消訂閱後可導出資料」，但導出的具體格式是什麼？

# 定位

Feature：取消訂閱流程
關聯決議：#8 取消訂閱處理

# 決議

**選項 A：SQL dump**

導出內容：
- 格式：標準 PostgreSQL pg_dump 格式
- 包含：Schema + 資料
- 可直接匯入任何 PostgreSQL 資料庫

不包含：
- 程式碼（用戶需另外從版本歷史下載）
- 環境變數（安全考量）

# 影響範圍

- 導出功能使用 Supabase 的 pg_dump API
- 簡化實作，不需處理多種格式
- 符合 GDPR 資料可攜權要求
