# 釐清問題

PRD 提到「內容審查」拒絕違法內容，但具體規則為何？使用哪個 moderation API？

# 定位

Feature：安全邊界（Section 7.2）
PRD：`moderationApi.check()`

# 決議

**選項 B：使用 Claude 內建的安全機制**

實作方式：
- 依賴 Claude API 本身的安全過濾
- 不額外串接第三方 moderation API
- Claude 拒絕生成違規內容時，回傳錯誤給用戶

優點：
- 無額外 API 成本
- 無額外延遲
- Claude 的安全機制持續更新

補充措施：
- 記錄被拒絕的請求供審計
- 若發現漏網之魚，加入關鍵字黑名單作為補充

# 影響範圍

- 移除 PRD 中的 `moderationApi.check()` 程式碼
- 錯誤處理需辨識 Claude 的安全拒絕回應
- 簡化架構，減少第三方依賴
