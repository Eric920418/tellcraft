# 釐清問題

決議「付費後可申請移轉資源到用戶自己的帳號」，但移轉流程是什麼？

# 定位

Feature：資源管理
關聯決議：#2 資源擁有權

# 決議

**選項 A：自助操作**

移轉流程：
1. 用戶在設定頁面點擊「移轉資源」
2. 輸入自己的 Supabase API Key 和 Vercel Token
3. 系統驗證 Key 有效性
4. 自動執行移轉（Supabase Project Transfer + Vercel Project Transfer）
5. 移轉完成後，平台不再管理該資源

注意：
- 移轉後無法回復（單向操作）
- 用戶需自行負責後續的 Supabase/Vercel 費用

# 影響範圍

- 需開發「資源移轉」自助功能
- 需串接 Supabase/Vercel 的 Transfer API
- 減少客服工作量
