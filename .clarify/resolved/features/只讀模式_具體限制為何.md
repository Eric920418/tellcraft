# 釐清問題

決議「取消後降級為只讀模式」，但只讀的具體限制是什麼？

# 定位

Feature：取消訂閱流程
關聯決議：#8 取消訂閱處理

# 決議

**選項 C：網站完全停用，僅顯示「已暫停」頁面**

實作方式：
- 取消訂閱後，網站所有頁面導向「已暫停」提示頁
- 提示頁顯示：
  - 「此網站已暫停服務」
  - 「網站擁有者：請在 30 天內登入 AI-Genesis 導出資料或重新訂閱」
  - AI-Genesis 登入連結
- 30 天後刪除資源

技術實作：
- Vercel 設定 redirect 規則
- 或部署一個靜態「已暫停」頁面覆蓋原網站

# 影響範圍

- 用戶網站的終端用戶會看到暫停頁
- 需設計「已暫停」頁面模板
- 簡化實作（不需處理部分功能開關）
