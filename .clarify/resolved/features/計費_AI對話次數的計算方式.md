# 釐清問題

「AI 對話次數/月」的計算方式為何？一次對話是指一輪問答，還是整個釐清流程？

# 定位

Feature：計費（Section 6.2）
PRD：「免費 50 次、創作者 200 次、專業 1000 次」

# 決議

**選項 A：每次用戶發送訊息 = 1 次**

計算規則：
- 用戶每發送一則訊息，消耗 1 次配額
- AI 回覆不計次
- 系統自動訊息（如歡迎語）不計次

範例：
- 用戶說「我要做預約網站」→ 消耗 1 次
- AI 問 3 個問題，用戶回答 3 次 → 消耗 3 次
- 一個完整專案可能消耗 10-30 次（視複雜度）

# 影響範圍

- 計費邏輯實作
- 用量顯示 UI（顯示「已使用 X / 50 次」）
- 定價策略：免費 50 次約可完成 1-2 個簡單專案
