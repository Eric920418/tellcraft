# 釐清問題

用戶取消訂閱或降級方案後，其 Supabase/Vercel 資源如何處理？

# 定位

Feature：計費模式（Section 6）
關聯：資源擁有權問題

# 決議

**選項 B + C + E：保留 30 天 + 只讀模式 + 提供導出**

處理流程：
1. **取消當下**：
   - 網站降級為只讀模式（可瀏覽，不可修改）
   - 發送通知告知用戶有 30 天處理期

2. **30 天內**：
   - 用戶可隨時導出資料（SQL dump + 程式碼 zip）
   - 用戶可重新訂閱恢復完整功能
   - 網站維持只讀運作

3. **30 天後**：
   - 若未導出且未重新訂閱 → 刪除資源
   - 刪除前 7 天再次提醒
   - 提供最後一次導出機會

用戶體驗：
- 不會突然斷線
- 有充足時間處理資料
- 符合 GDPR 資料可攜權

# 影響範圍

- 計費系統需追蹤「取消日期」
- 需實作「只讀模式」（停用寫入 API）
- 需實作「資料導出」功能
- 排程任務：30 天後清理
