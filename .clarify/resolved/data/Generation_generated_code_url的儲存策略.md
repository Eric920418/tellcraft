# 釐清問題

`generations.generated_code_url` 指向 R2/Storage URL，但儲存策略未定義。程式碼保留多久？版本如何管理？

# 定位

ERM：`generations` 實體的 `generated_code_url` 屬性

# 決議

**選項 A：永久保留所有版本**

儲存策略：
- 每次生成的程式碼都永久保留
- 用戶可在「版本歷史」中查看所有版本
- 可隨時回滾到任何歷史版本

實作考量：
- 使用 Cloudflare R2 或 S3（成本較低）
- 程式碼壓縮後通常 < 10MB
- 預估每用戶每年 < 100MB（可接受）

例外：
- 用戶主動刪除專案時，一併刪除所有版本
- 用戶取消訂閱 30 天後刪除（依取消策略）

# 影響範圍

- 儲存成本預估需納入永久保留
- 版本歷史 UI 設計
- 回滾功能實作
